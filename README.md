## English

Brings Red Dead Redemption 2's Dead Eye to The Long Dark.

### Features

- Bind a revolver in the settings; while carrying it, press the bound key to enter Dead Eye, mark animals, then press the key again to fire.
- Choose the revolver skill level that unlocks the mode (1~5); below it the toggle does nothing.

### Requirements

- The Long Dark **2.55** (built against 2.55)
- [MelonLoader](https://melonwiki.xyz/) **0.7.3** or newer (tested on 0.7.3)
- **ModSettings** (required; the settings page depends on it)

### Installation

1. Drop everything from the `Mods` folder in the zip into the game's `Mods` folder.
2. Start the game.

### Compatibility

- **AdaptiveArsenal compatible**: detected automatically, shots land on the mark either way.
- Likely incompatible with HuntingRoads' projectile system, though its scopes still work.

See [ChangeLog.md](ChangeLog.md) for version history.

## 中文

为《漫漫长夜》引入rdr2的死神之眼

### 功能

- 在设置菜单里绑定左轮，携带该左轮时快捷键开启死神之眼，标记动物，再按一次死神之眼开枪
- 设置里可选解锁所需的左轮技能等级（1~5），没达到时快捷键不生效

### 前置

- 《The Long Dark》**2.55**（本 mod 针对 2.55 编译）
- [MelonLoader](https://melonwiki.xyz/) **0.7.3** 或更高（实测环境 0.7.3）
- **ModSettings**（必需，设置页依赖它）

### 安装

1. 把 压缩包里Mods文件夹中的所有文件丢进游戏根目录的Mods文件夹
2. 启动游戏。

### 兼容性

- **与 AdaptiveArsenal 兼容**：自动探测，装不装都能命中标记点。推荐安装AdaptiveArsenal。
- 应该与HuntingRoads的子弹系统不兼容，但可以用它的瞄准镜。
